## Overview

Kann AI Labs Scan is an AI-powered Solidity smart contract security auditor. It integrates directly into your development workflow to help identify vulnerabilities, logic errors, and security risks in your code.

---

## Installation

**1. Clone the repository**

```bash
git clone https://github.com/KannAILabs/AI-Security-Auditor
cd AI-Security-Auditor
```

**2. Install the auditor command**

```bash
mkdir -p .opencode/skill && cp -r solidity_auditor/  .opencode/skill/solidity-auditor
```

---

## Usage

Once installed, the auditor is available as a command inside your OpenCode environment. Just type audit to start the process.
